# ② 案例模板（Case Templates）v1.1

> 六份可直接套用的模板，把本工程的验收流程抽象成"陌生题目也能用"的骨架。
> 模板 A–D：常规验收流程；模板 E–F：频率/启动链变更、提交前合规（这两类最容易"以为做完了"）。

## 模板 A：上板 Bring-up 检查清单

> 适用：任何"PC 工程 → 板端运行"的题目。按顺序勾选，任一项失败先修再继续。

```markdown
## A1 硬件与连接
[ ] 板子供电正常（电压/电流符合手册）
[ ] JTAG 被识别（设备管理器/`lsusb` 能看到下载器 VID:PID）
[ ] 串口被识别（能看到 COM 口）
[ ] SD 卡（或 Flash）可被电脑读写

## A2 最小可运行
[ ] 位流可下载，PS 能启动（串口有启动打印）
[ ] 只跑 1 帧/1 个测试用例，能正常结束（有结束标记）
[ ] 单帧耗时打印合理（与 PC 估算相差 < 5 倍）

## A3 数据通路
[ ] 输入文件在板上可读（打印文件长度/哈希，或读一个字节看是否成功）
[ ] 输出能传回（串口/文件/网络任一通道验证通）
[ ] 同一输入重复跑两次，结果一致（确定性）

## A4 正确性
[ ] 与 PC 参考结果对同一输入，误差在可接受范围（记录数值）
[ ] 断电重启后再跑一次，结果一致
[ ] 异常输入（缺失文件/错误尺寸）能报错而不是输出垃圾
```

## 模板 B：串口数据抓取脚本骨架（PowerShell）

> 适用：板端通过 UART 输出结果、需要"从本次运行开始记录"的场景。
> 本工程实际脚本见 `../../board/scripts/read_serial.ps1`，关键点如下：

```powershell
# 1) 打开串口（115200-8-N-1）
$sp = New-Object System.IO.Ports.SerialPort $Port,115200,'None',8,'One'
$sp.ReadTimeout = 500
$sp.Open()

# 2) 先清空缓冲（关键！否则会读到上次运行的残留数据）
$drainUntil = (Get-Date).AddSeconds(1.5)
while ((Get-Date) -lt $drainUntil) { try { [void]$sp.ReadExisting() } catch {}; Start-Sleep -Milliseconds 100 }

# 3) 等到"本次运行的启动标记"才开始记录
$recording = $false
while ((Get-Date) -lt $deadline) {
    $s = $sp.ReadExisting()
    if ($s -and -not $recording) {
        $i = $s.IndexOf('Yolo4 Tiny Test')     # ← 换成你的程序启动标记
        if ($i -ge 0) { $recording = $true; $s = $s.Substring($i) }
    }
    if ($recording) {
        [void]$sb.Append($s)
        if ($s -match 'ALL DONE') { break }    # ← 换成你的程序结束标记
    }
}
```

**失效条件**：程序输出没有明确的启动/结束标记 → 需先加标记（本工程就是在固件里补了 `ALL DONE`）。

|---|---|---|---|---|---|---|

| <数据集2> |   |   |   |   |   |   |

## 结论模板
- 量化损失：板端比 PC 低 X 个百分点（合理范围 2~5 pp）

## 模板 E：时钟/启动链变更核对表（防"时钟未生效"）

> 适用：改 PS FCLK、改 PS 配置、换位流后"板子行为没变"的场景。
> 判据：**每项都要有证据**（寄存器值/二进制特征/实测耗时），不能只看"我改了"。

```markdown
## E1 设计侧
[ ] BD 中 FCLK 属性已改（grep 时钟频率配置项，确认新值）
[ ] 重新综合+实现，记录新位流 SHA256
[ ] 新时序报告：WNS ≥ 0、失败端点 = 0

## E2 启动链四件套（缺一不可）
[ ] 从新实现导出 HDF，`ps7_init.c/h/tcl` 已更新
[ ] hw platform 中 `ps7_init.*` 已替换（不是只改工程目录里的副本）
[ ] FSBL 已重新编译；在 FSBL ELF 二进制中能搜到新时钟寄存器值
[ ] BOOT.bin 已重打（bootgen：FSBL + 新位流 + 应用 ELF）
[ ] JTAG 下载脚本使用新的 `ps7_init.tcl`

## E3 上板验证
[ ] 帧时间按频率比例变化（与理论值比较，允许 ±2%）
[ ] 关键点/分类结果与改前**逐位一致**（频率只影响耗时，不应影响数值）
[ ] 串口启动头/结束标记正常，无读文件错误
```

**本工程实测**：按本表补齐 FSBL/BOOT 后，板端帧时间与理论值一致，且关键点结果逐位一致（详见 `pitfalls.md` P18）。
