## 模板 A：上板 Bring-up 检查清单

> 适用：任何"PC 工程 → 板端运行"的题目。按顺序勾选，任一项失败先修再继续。

```markdown
## A1 硬件与连接
[ ] 板子供电正常（电压/电流符合手册）
[ ] JTAG 被识别（设备管理器/`lsusb` 能看到下载器 VID:PID）
[ ] 串口被识别（能看到 COM 口）
[ ] SD 卡（或 Flash）可被电脑读写

## A2 最小可运行
[ ] 位流可下载，PS 能启动（串口有启动打印）
[ ] 只跑 1 帧/1 个测试用例，能正常结束（有结束标记）
[ ] 单帧耗时打印合理（与 PC 估算相差 < 5 倍）

## A3 数据通路
[ ] 输入文件在板上可读（打印文件长度/哈希，或读一个字节看是否成功）
[ ] 输出能传回（串口/文件/网络任一通道验证通）
[ ] 同一输入重复跑两次，结果一致（确定性）

## A4 正确性
[ ] 与 PC 参考结果对同一输入，误差在可接受范围（记录数值）
[ ] 断电重启后再跑一次，结果一致
[ ] 异常输入（缺失文件/错误尺寸）能报错而不是输出垃圾
```

## 模板 B：串口数据抓取脚本骨架（PowerShell）

> 适用：板端通过 UART 输出结果、需要"从本次运行开始记录"的场景。
> 本工程实际脚本见 `../../board/scripts/read_serial.ps1`，关键点如下：

```powershell
# 1) 打开串口（115200-8-N-1）
$sp = New-Object System.IO.Ports.SerialPort $Port,115200,'None',8,'One'
$sp.ReadTimeout = 500
$sp.Open()

# 2) 先清空缓冲（关键！否则会读到上次运行的残留数据）
$drainUntil = (Get-Date).AddSeconds(1.5)
while ((Get-Date) -lt $drainUntil) { try { [void]$sp.ReadExisting() } catch {}; Start-Sleep -Milliseconds 100 }

# 3) 等到"本次运行的启动标记"才开始记录
$recording = $false
while ((Get-Date) -lt $deadline) {
    $s = $sp.ReadExisting()
    if ($s -and -not $recording) {
        $i = $s.IndexOf('Yolo4 Tiny Test')     # ← 换成你的程序启动标记
        if ($i -ge 0) { $recording = $true; $s = $s.Substring($i) }
    }
    if ($recording) {
        [void]$sb.Append($s)
        if ($s -match 'ALL DONE') { break }    # ← 换成你的程序结束标记
    }
}
```

**失效条件**：程序输出没有明确的启动/结束标记 → 需先加标记（本工程就是在固件里补了 `ALL DONE`）。

## 模板 C：GT 精度评测表

> 适用：带关键点/检测框 GT 的题目。评测口径要写清楚，否则数字不可比。

```markdown
## 数据
- 序列：<厂商/切面/节段>，共 N 帧
- 图片尺寸：W×H
- GT 格式：`cls cx cy w h`（归一化）

## 评测口径
- 预测坐标：板端输出归一化坐标 × 实际图片尺寸
- 命中条件：dist(pred, gt_center) ≤ max(w_px, h_px)/2 + 4 px

## 结论模板
```
